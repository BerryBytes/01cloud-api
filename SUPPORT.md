# Support

Use this guide to choose the right channel when you need help with `01cloud-api`.

## Where To Ask

- GitHub Issues: bugs, reproducible defects, and clearly scoped feature requests
- Pull Requests: proposed code changes that are ready for review
- Security reports: private disclosures only, following [SECURITY.md](SECURITY.md)

## Before Opening An Issue

- Check the README and contribution guide
- Search existing issues and pull requests for duplicates
- Gather reproduction steps, logs, versions, and relevant configuration details

## What Maintainers Need

The more concrete your report is, the easier it is to help:

- what you were trying to do
- what happened instead
- how to reproduce it
- your environment details
- any logs, screenshots, or API payloads that clarify the problem

## Security Contact

For vulnerabilities or sensitive reports, email `info@01cloud.com` instead of opening a public issue.
